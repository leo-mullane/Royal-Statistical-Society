Search

BehaviourOne index and one results page for every content type: pages, events and courses, news, policy documents (including the text inside them), sections and groups, experts and jobs. Every search box on the site uses it. Results are ranked by page type first, so an expert, a section or a key page comes before a passing mention in a news story, and documents come last. Try Adaeze Okafor, medical section, chartered statistician (finds CStat holders through a synonym), bayseian (a typo), response rates (inside a PDF) or a search with no results. With nothing typed, the page shows everything by type. REQ-037, REQ-038, REQ-044
BehaviourTabs by type, with counts that stay accurate while one tab is showing. Each tab offers only the filters that make sense for it. REQ-038, REQ-039
