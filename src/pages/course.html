Introduction to R

Import, tidy, summarise and plot data in R, with practical exercises throughout. No previous programming needed.

What you will learn

  • Read data from spreadsheets and databases
  • Reshape and summarise data with the tidyverse
  • Make clear, reproducible charts
  • Write simple functions and scripts

Who it is for

Analysts and researchers who use spreadsheets or point-and-click software and want to move to code.
