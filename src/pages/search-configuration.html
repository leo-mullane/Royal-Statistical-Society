How search is configured

Everything on this page is read from one configuration object that the search engine uses. Changing how search ranks, which synonyms it knows or which filters it offers means editing that data, not the code.

CMSIn the build, these settings would be held in the CMS or the search service's configuration, so they can be changed without a release. Which of them editors can change themselves (for example synonyms and promoted results, both Coulds) is to be agreed. REQ-037, REQ-047, REQ-278

All the people, employers and documents in the prototype are fictional.
